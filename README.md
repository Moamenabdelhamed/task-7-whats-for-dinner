# What's For Dinner

A responsive recipe page built with HTML, CSS, Bootstrap, and beginner-friendly JavaScript.

## Run the site

Open `index.html` in a browser. The styles, scripts, icons, fonts, and food photos are included in this repository.

## Project files

- `index.html` — page structure
- `css/` — Bootstrap and site styles
- `JS/` — Bootstrap bundle and recipe interactions
- `images/` — recipe photos, avatar, and favicon
- `segoe-ui-4-cufonfonts/` — local font files
- `webfonts/` — Font Awesome icon fonts
